One original line (max 200 characters) roasting a gadget used every day, for the [make.fun](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610) bounty "One-Line Roast: The Gadget You Use Every Day".

## The line

> My smartwatch just congratulated me for standing up. I have been awake for nine hours — the bar is on the floor, and so, apparently, am I.

A smartwatch that throws a party for the bare minimum: nine hours awake, one stand, one congratulation. The bar is on the floor.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), validated to be 1–200 characters, a single line, no trailing newline.
